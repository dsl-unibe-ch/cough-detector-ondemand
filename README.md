# Equine Cough Detector — Open OnDemand app

Open OnDemand app definition for the **Equine Cough Detector**, a tool that detects
cough events in long audio recordings of horses. Batch-processes a folder of
recordings on a GPU node and returns per-file and per-folder PDF/CSV reports.

Built and maintained by the [Data Science Lab](https://www.dsl.unibe.ch/), University
of Bern. The application source and model weights are not public; this repository
holds only the OnDemand launcher configuration.
